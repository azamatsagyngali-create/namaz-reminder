# Намаз еске салу

Telegram-топқа бес уақыт намаздың еске салуын жібереді:
- намаз кірерден **30 минут бұрын**;
- намаз кіргеннен **30 минут кейін** («оқыдың ба?»).

Уақыттар ДУМК-тің ресми кестесінен (namaz.muftyat.kz) алынады. Әдепкі қала: Астана.
GitHub Actions арқылы әр 10 минут сайын іске қосылады (`.github/workflows/prayer.yml`).

## Баптау
Репозиторийдің **Settings → Secrets and variables → Actions** бөліміне екі secret қос:
- `BOT_TOKEN` — Telegram бот токені
- `CHAT_ID` — топтың chat_id

Басқа қалаға ауыстыру үшін workflow-ға `LAT` және `LNG` айнымалыларын қос.
